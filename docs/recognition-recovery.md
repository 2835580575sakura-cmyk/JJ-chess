# 0.1.1：静止棋盘无法识别的恢复

用户报告静止棋盘一直显示“画面不清晰，等待稳定棋盘”。截图中可见完整绿色 JJ 棋盘、金色棋子和标准开局，悬浮窗位于棋盘外。

确认的代码问题：

- 原定位仅允许 ±0.5% 的棋盘比例微调；宽度差约 1.8% 的回放即可使整盘识别失败。扩大粗定位范围，并纳入底线、补充细定位后回放通过。
- 原字迹特征只看红绿差值，金色底色可能被算作红字。使用保持原置信度门槛的金色底色回放复现失败，限制亮底色参与红字判断后通过。
- 任意一格未知就拒绝整盘，同时“校验”要求已有整盘结果，形成等待无法解除的流程死路。现在明确显示未知格数、坐标越界或遮挡原因，并提供校准与开局适配入口。

可选的适配流程从用户明确确认的标准开局提取 32 枚棋子的字形。学习前检查全部 90 格的占位和红黑方向；学习后要求能完整区分该开局，才允许安装模型。不是标准开局、存在遮挡或方向错误时拒绝学习。用户确认开局后，仍须返回 JJ 并读到匹配的新鲜稳定棋盘，才开始搜索。未识别的中途局面不会被自动替换成开局。

只在应用私有目录保存归一化字迹特征，不保存用于学习的整屏图片。下次启动加载特征；损坏文件退回内置模型。升级后旧版校准失效，让新版重新定位；当前校准和设置可继续保存。保持原包名与签名，版本号提升至 0.1.1 / versionCode 2。

新增回归覆盖：缩窄棋盘、金色底色、未知格计数、越界和吃子动画分类、模型保存与损坏恢复、用开局适配后识别保留样本及翻转、拒绝非开局学习、暂停适配后等待新鲜匹配画面、未知时清除旧箭头，以及校验恢复入口。完整结果见 [验证记录](validation-results.md)。

本次收到的截图以内联图像提供，没有作为可读取的原图文件挂载，因此没有对该截图做逐像素重放。回归图来自已有录像的棋盘裁剪及受控变形，不能等同于已经验证用户手机上的新版识别。新旧模型均保留未知格、置信度、三帧稳定与原生规则校验，不通过降低门槛输出猜测走法。
