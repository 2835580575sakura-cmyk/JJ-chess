# 手机象棋分析助手

Android 10+、ARM64、离线运行，面向 iQOO Neo9S Pro+ 上 JJ 象棋的人机练习。读取录屏画面，识别稳定局面，用 Pikafish 给出箭头和中文走法；由你手动落子。无需电脑、Root 或无障碍权限。

**当前交付为待真机验收的首版。** 云端已验证构建、录像样本识别和真实引擎搜索；尚未在目标手机上执行录屏、悬浮穿透或温度测试。识别器适配所提供视频的木纹棋盘皮肤，不能保证其他皮肤、分屏和所有动画都能识别。

## 安装与使用

1. 将 `dist/xiangqi-assistant-0.1.0-arm64.apk` 下载到手机，在文件管理中安装。按系统提示允许该来源安装应用。
2. 打开「象棋分析助手」，授予悬浮窗权限。选择我方红/黑、屏幕下方红/黑、首次轮到谁走，及 3/15/30 秒思考时间。默认 4 线程、256 MiB Hash、15 秒；更长时间通常更深入，但没有固定棋力或“世界最强”的保证。
3. 点「开始分析」，在系统弹窗授权**整个屏幕**录制；若有通知权限提示则允许。然后切换到 JJ 象棋的人机棋盘。
4. 等待悬浮窗提示已识别，点「校验」。逐格核对棋子，点错格修改；确认当前行棋方。若识别位置不准，先用「校准棋盘位置」拖动两个蓝色角到棋盘的左上、右下交点。
5. 返回 JJ，等待计算结束，按箭头或中文走法手动落子。对方回合不显示我方箭头。箭头采样时短暂隐藏属于正常行为。
6. 悔棋、重开、连续漏看多步、换皮肤或翻转后重新校验；翻转或尺寸改变时停止并重新开始，重新选择底方和校准。上一局历史只有与画面匹配并经手动确认后才能恢复。
7. 悬浮窗「暂停」和「停止」、通知栏「停止」均可控制会话。停止会释放录屏和引擎。锁屏、撤销录屏或系统终止后需重新授权。

OriginOS 若关闭后台运行，可在系统的应用电池/后台管理中允许本应用必要的后台活动；具体菜单随系统版本变化。开始后悬浮窗未出现，先检查悬浮权限，再查看通知是否仍在。

严重过热会暂停，降温后手动继续；内存紧张会停止并将下次配置降至 2 线程、128 MiB。请手动重新开始。Hash 并非应用总内存。未知棋子和异常局面不会生成猜测箭头。

「导出棋盘诊断」只在主动点击后创建棋盘裁剪和固定错误类型记录。默认不存整屏录像、不联网、不上传画面。屏幕预览仅保留在内存。应用持久化设置、与尺寸和方向绑定的校准参数，以及最近确认的局面历史；恢复历史不等于自动确认当前棋局。
